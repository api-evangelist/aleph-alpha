# Aleph Alpha

Aleph Alpha is a Heidelberg, Germany based sovereign AI company building PhariaAI, an end-to-end,
customizable AI suite for enterprises and governments that can be deployed on-premise or hosted.

PhariaAI is exposed through six documented HTTP APIs, all published as OpenAPI or Swagger
definitions on the Aleph Alpha documentation site:

| API | Spec | Operations |
|---|---|---|
| PhariaInference (Aleph Alpha API) v4.7.0 | OpenAPI 3.0.3 | 28 |
| PhariaData | OpenAPI 3.0.1 | 54 |
| PhariaStudio | OpenAPI 3.1.0 | 42 |
| PhariaSearch / Document Index | OpenAPI 3.1.0 | 34 |
| Responses (Stateful Responses) | OpenAPI 3.1.0 | 15 |
| PhariaOS Manager | Swagger 2.0 | 21 |
